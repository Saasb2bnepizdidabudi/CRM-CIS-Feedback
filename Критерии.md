# Критерии отбора

Чтобы компания попала в этот список, её процесс найма **ни на одном из этапов** не должен включать следующее:

- Собеседование по кругу (Over-interviewing): **Больше 4 этапов собеседований на линейную или старшую позицию**, когда кандидата по очереди заставляют знакомиться со всеми отделами компании без четкой цели.
- Заставлять кандидата **проходить больше одного этапа тестовых без участия нанимающего менеджера** или отдела кадров (Сбер, привет)
- Давать **огромные бесплатные тестовые задания в виде готовых CRM-стратегий на год вперед** (это классический бесплатный консалтинг, а не проверка навыков).
